# Instruções para o Claude

Site estático (HTML, CSS e JS puros, sem build). Siga o `CONTRIBUTING.md` para branches e commits.

## Pull requests automáticos
O Claude pode abrir e fazer merge de pull requests sozinho neste repositório, desde que antes confira:
- todos os links e arquivos referenciados (href, src, url() no CSS) existem;
- o site abre localmente sem erros no console, no desktop e no celular;
- o menu mobile e as páginas em pages/ continuam funcionando.
Mudanças grandes (redesenho, remoção de páginas, textos do cliente) ficam aguardando revisão.

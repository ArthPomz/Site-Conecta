# Registro de decisões

Cada decisão importante do projeto fica registrada aqui, com a data e o motivo.

## 2026-10-20: HTML, CSS e JavaScript puros

**Decisão:** começar sem framework e sem etapa de build.
**Motivo:** é um site institucional de poucas páginas. Assim ele é simples de manter e roda direto no GitHub Pages. Se no futuro precisar de blog ou muitas páginas, dá para migrar para um gerador como o Astro.

## 2026-10-20: Hospedagem

**Decisão:** GitHub Pages, a confirmar.
**Motivo:** gratuito e integrado ao repositório. Dá para usar o domínio próprio do cliente.

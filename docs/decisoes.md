# Registro de decisões

Cada decisão importante do projeto fica registrada aqui, com a data e o motivo.

## 2026-10-20: HTML, CSS e JavaScript puros

**Decisão:** começar sem framework e sem etapa de build.
**Motivo:** é um site institucional de poucas páginas. Assim ele é simples de manter e roda direto no GitHub Pages. Se no futuro precisar de blog ou muitas páginas, dá para migrar para um gerador como o Astro.

## 2026-10-20: Hospedagem

**Decisão:** GitHub Pages, a confirmar.
**Motivo:** gratuito e integrado ao repositório. Dá para usar o domínio próprio do cliente.

## 2026-10-20: Cores e logo

**Decisão:** usar o azul do logo (`#2F5A8C`) como cor principal e o padrão de circuito como fundo da página inicial.
**Motivo:** manter o site igual à identidade que o cliente já usa. Detalhes em [identidade-visual.md](identidade-visual.md).

## 2026-10-20: Novo estilo visual

**Decisão:** seguir a linha visual de sites de contabilidade digital, como a Contabilizei, com cabeçalho branco, títulos grandes, botões em pílula, cartões arredondados e perguntas frequentes.
**Motivo:** pedido do cliente. Só o estilo foi usado como referência: textos, telas e informações são da Conecta. Detalhes em [identidade-visual.md](identidade-visual.md).

# Identidade visual

> Valores provisórios. Substituir pelos oficiais quando o cliente enviar o logo e o manual da marca.

## Cores

| Uso | Cor | Variável CSS |
| --- | --- | --- |
| Principal | `#0B3D5C` | `--cor-principal` |
| Destaque | `#1FA37A` | `--cor-destaque` |
| Texto | `#1F2933` | `--cor-texto` |
| Fundo | `#FFFFFF` | `--cor-fundo` |
| Fundo alternativo | `#F3F6F8` | `--cor-fundo-alt` |

As variáveis ficam no topo de `assets/css/style.css`. Mudando ali, o site inteiro muda.

## Tipografia

- Fonte: [Inter](https://fonts.google.com/specimen/Inter) (Google Fonts).

## Logo

- Colocar os arquivos em `assets/img/` (de preferência `logo.svg` e `logo.png`).
